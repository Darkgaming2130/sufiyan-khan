# Sufiyan Khan Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Included sections
- Hero / introduction
- About
- Skills
- Projects
- Certificates placeholders
- Contact links

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Or open the folder in VS Code and use the Live Server extension.

## What to customize before publishing
- Replace certificate placeholders with your verified certificate titles.
- Replace GitHub, LinkedIn and email links.
- Add a profile photo if you want one.
- Add project repository/demo links when available.

## Deploy free
You can publish this with GitHub Pages after pushing the folder to a repository.
